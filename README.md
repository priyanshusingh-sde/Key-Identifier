# Key Identifier

A simple and interactive keyboard key visualizer built using HTML, CSS, and JavaScript.

## Features

- Detects keyboard key presses
- Displays pressed key on screen
- Special handling for Spacebar (`SPC`)
- Dynamic gradient background effect
- Minimal modern UI
- Responsive text sizing
- Smooth flash animations

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

- The app listens for `keydown` events
- Whenever a key is pressed:
  - The key name appears on screen
  - Background flashes with a gradient effect
  - Text disappears after a short delay
